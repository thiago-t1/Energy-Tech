⚡ EnergyTech


Projeto de página de apresentação responsiva desenvolvido como atividade acadêmica. O site apresenta a EnergyTech, uma solução focada em transformar energia solar em economia para clientes residenciais, empresariais e investidores.

🔗 Acesse o site ao vivo: https://thiago-t1.github.io/Energy-Tech/

🎯 Objetivo do Projeto
O objetivo principal foi criar uma landing page (página de apresentação) completa e responsiva para uma empresa de tecnologia de energia. O site serve como um portfólio digital, demonstrando competências em desenvolvimento front-end, ao mesmo tempo em que apresenta uma solução de mercado de forma clara e atrativa.

✨ Funcionalidades Principais
Design Responsivo: A interface se adapta perfeitamente a dispositivos móveis, tablets e desktops.

Apresentação de Soluções: Seções dedicadas para os públicos Residencial, Empresarial e de Investimento.

Navegação Intuitiva: Um menu de navegação (navbar) fixo que facilita o acesso às seções: Início, Soluções, Sobre Nós, Objetivos e Contato.

Interatividade com JavaScript: O projeto inclui elementos interativos, como um modal de Login/Cadastro.

Páginas Adicionais: O site é composto por múltiplas páginas (index.html, contato.html, financeiro.html) para organizar a informação.

🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias web:

HTML5: Utilizado para a estrutura semântica de todas as páginas.

CSS3: Utilizado para a estilização completa, layout (Flexbox/Grid) e responsividade (media queries).

JavaScript: Utilizado para adicionar interatividade e manipular o DOM (ex: funcionalidade do modal).
